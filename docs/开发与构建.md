# 开发与构建

## 开发

在项目根目录运行：

```bash
npm install
npm run dev
```

终端会显示本地地址（通常是 `http://localhost:5173`）。日常修改只在 `src/` 中进行，浏览器会自动刷新。

## 构建与预览

```bash
npm run build
npm run preview
```

`npm run build` 会清空并重新生成 `dist/`，同时更新可独立分享的网页模板。不要手动修改 `dist/`，否则下一次构建会覆盖改动。

## 发布

将整个 `dist/` 文件夹上传到静态托管平台即可。不要上传 `node_modules/`、`src/` 或本地工作文件夹预设。
