# 批量图片填字工具 · 使用说明

## 标准流程

1. 本地开发时在项目根目录运行 `npm run dev`，并打开终端显示的本地地址；或访问已部署的网站地址。
2. 点击画布空白区域，或把底图拖入画布。
3. 在右侧“批量文字”输入内容，每行会生成一张图片。
4. 在左侧设置文字样式和文字区域。
5. 在中央画布检查第一条内容的实际效果。
6. 在下方“批量结果预览”检查结果，然后复制、下载或批量导出。

空行会自动忽略。生成文件会保持底图的原始像素宽高。

## 保存配置预设

点击页面右上角的“配置预设”，输入名称后保存当前配置。每组预设会记住文字样式、下边线、文字区域位置与尺寸、批量文字和输出设置；如果当前载入了底图或本机字体文件，也会连同原文件一起保存。

保存前可以先看弹窗中的“当前将保存的配置”：它会列出底图、批量条数、文字样式、文字区域、下边线和输出设置。点击已有预设的“覆盖”不会立刻写入；请先确认上方摘要与覆盖目标，再点击“确认覆盖并保存”。

最多保存 10 组。新保存或覆盖的预设会自动成为下次打开工具时载入的默认项。列表中可随时“载入”“覆盖”“设为默认”或“删除”。存满 10 组时可以覆盖已有预设，或删除不再需要的一组后再保存。

有底图的预设会显示底图缩略图，便于区分不同模板；没有底图的预设显示“无底图”。此前保存的预设首次打开列表时会自动补生成缩略图。

预设保存在当前浏览器的本地网站数据中，不会上传到服务器。请用同一个浏览器和相同的访问地址打开工具；`file://` 与本地服务器地址分别拥有自己的存储。清除浏览器网站数据、使用无痕窗口或换设备后，预设可能无法保留。重要配置请勿只依赖浏览器存储。

### 把预设交给别人

- 在预设列表中点击“导出预设文件”，会得到一个 JSON 文件。接收者打开自己的工具，点击“配置预设 → 导入预设文件”，即可载入并保存为其本机默认配置。
- 点击“生成共享网页”，会得到一个独立的 HTML 文件。把这个文件发给别人，对方直接双击打开，就会自动载入该预设；不需要另外拷贝工具文件夹，也不需要联网。对方还可以点击“存到本机”。
- 两种文件都会包含预设的批量文字，以及保存时附带的**原始底图和本机字体**。分享前请确认可以交给接收者；有大图或字体时文件也会较大。
- 导入的预设占用 10 个本机名额之一。共享网页附带的预设不占名额，且不会自动覆盖接收者已有的本机预设。

### 随整个工作文件夹分享

1. 点击“配置预设 → 连接工作文件夹”，选择包含 `dist/` 的工具文件夹，并同意浏览器的读写授权。推荐使用新版 Chrome 或 Edge。
2. 如果已有浏览器本机预设，点击“同步本机预设”；也可以输入名称后点击“保存当前配置到文件夹”。连接期间，之后通过上方按钮保存或覆盖本机预设，也会同步到该文件夹。
3. 工具会自动创建 `presets/manifest.json` 保存参数，并在 `presets/assets/` 保存原始底图、字体与缩略图。把**整个工具文件夹**复制或打包交给对方，不要只发清单。
4. 对方在项目根目录执行 `npm install`、`npm run build` 后，打开生成的 `dist/index.html`；进入“配置预设”，点击“只读打开文件夹”并选择收到的文件夹。若还想直接修改文件夹中的配置，可用“连接工作文件夹”授予读写权限。没有正在编辑的内容时，工具会载入文件夹默认预设；其他预设可在列表中选择“载入”。

浏览器出于安全原因不会在打开网页时自动读取旁边的文件夹，接收者需要明确选择并授权。若希望对方双击单个文件就直接使用，请用上面的“生成共享网页”。
`presets/` 会在第一次执行“同步本机预设”或“保存当前配置到文件夹”时创建；之后再复制或重新压缩这个已更新的工作文件夹。

## 画布操作

- **缩放画布**：根据顶部选择的模式，使用单滚轮或 `Ctrl + 滚轮`。
- **横向移动**：按住 `Shift` 滚动鼠标滚轮。
- **自由平移**：在文字区域之外按住鼠标并拖动。
- **适应窗口**：点击画布顶部的“适应”。
- **查看原始比例**：点击“100%”。

## 文字区域操作

- 点击文字可进入编辑状态，未选中时编辑边框会隐藏。
- 拖动文字区域可改变位置。
- 拖动四条边或四个角可缩放文字区域，文字大小会同步变化。
- 在文字区域内滚动鼠标滚轮可缩放文字。
- 按方向键可按原图像素微调；`Shift + 方向键` 每次移动 10 像素。
- 双击文字区域可恢复默认位置和尺寸。
- 输入更长的文字时，文字区域会自动向右生长，并保持单行显示。

## 输出与质量

点击“批量导出”后，在弹窗中选择图片格式和质量。图片质量按 5% 分为 20 档，可点击或拖动选择；默认值为 100%。

- **PNG**：适合文字、海报和需要稳定清晰度的图片。
- **JPEG**：适合照片，文件通常更小。
- **WebP**：适合兼顾画质与文件大小的场景。

批量导出时工具会逐张生成并及时释放中间结果，避免同时把整批原图保存在内存中。“停止导出”仅在任务进行中可用。

## 字体与颜色

- 默认字体为黑体，默认字号为 54 原图像素。
- 可以载入 `.ttf`、`.otf`、`.woff` 或 `.woff2` 本机字体文件。
- 色号支持输入 `ECD6AB` 或 `#ECD6AB` 两种形式。
- 本机字体只在当前浏览器会话中加载，不会被上传。

## 常见问题

### 无法复制图片

剪贴板写入可能受到浏览器或 `file://` 页面权限限制。请优先使用 Chrome 或 Edge，也可以改用“下载当前图片”。

### 无法选择导出文件夹

部分浏览器不支持目录写入。可以改用逐张下载，或通过本地静态服务器打开工具。

### 关闭页面后配置是否保留

当前版本不会把底图、字体或批量文字上传到远端。重要结果请在关闭或刷新页面前完成导出。
