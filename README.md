# 批量图片填字工具

> 版本：v1.3.1 · 本地版

在一张底图的指定位置批量写入不同文字，并按原始分辨率复制、下载或导出图片。所有图片处理均在浏览器本地完成，不会上传到服务器。

## 快速开始

1. 安装 Node.js 后，在项目根目录运行 `npm install`。
2. 运行 `npm run dev`，并打开终端显示的本地地址。
3. 在画布中点击或拖入一张底图。
4. 在右侧“批量文字”中每行输入一条内容。
5. 设置字体、颜色和文字区域，并在画布中确认位置。
6. 在“批量结果预览”中复制、下载或批量导出。

无需安装，无需联网，无需构建。

## 主要能力

- 保持底图原始像素尺寸生成，不降低分辨率。
- 支持本机字体、字号、字重、字距、颜色和对齐方式。
- 支持文字下边线及其颜色、粗细、间距与左右延伸。
- 支持画布缩放、平移，以及文字区域的拖动、缩放和方向键微调。
- 支持 PNG、JPEG、WebP 与分段图片质量设置。
- 使用单画布逐张生成，避免批量任务长期占用大量内存。
- 支持复制当前图片、下载单张图片及选择文件夹批量导出。
- 最多保存 10 组本地配置预设；最近保存的预设下次自动载入，底图和本机字体可随预设一起保存。
- 带底图的预设会显示轻量缩略图，方便在列表中辨认。
- 保存前展示当前配置摘要；覆盖已有预设时先明确目标，再确认保存。
- 每组预设可导出为便携 JSON 文件供别人导入，或生成内含预设的独立 HTML 网页，接收者双击即可使用。
- 可将预设参数、原始底图和本机字体保存到工作文件夹的 `presets/` 中。分享整个文件夹后，接收者选择该文件夹即可载入。

## 浏览器建议

推荐 Chrome 或 Edge。剪贴板写入、目录选择等能力由浏览器提供；本地开发请使用 `npm run dev`，不要直接双击源码文件。

## 数据与隐私

- 图片、文字和字体仅在当前浏览器页面中处理。
- 工具不包含网络上传或远程存储逻辑。
- 预设保存在当前浏览器的网站数据中，不会同步到其他浏览器或设备；清除网站数据也会清除预设。
- 连接工作文件夹后，工具会自动创建 `presets/`，并将新保存或覆盖的本机预设同步进去；也可点击“同步本机预设”迁移已有配置。浏览器必须先获得文件夹访问授权，无法未经选择自动读取相邻文件。
- 导出的预设文件和共享网页会包含所选原始底图、批量文字与本机字体；请只分享给信任的人。共享网页不依赖原工具文件夹，但文件体积可能较大。
- 未保存为预设的改动在刷新后不会保留；图片成品仍需单独下载或导出。
